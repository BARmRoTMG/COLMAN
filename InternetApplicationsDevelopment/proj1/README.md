# LinkedIn Clone — Project 1

Static recreation of LinkedIn's login and main feed pages.

## Pages
- `login.html` — Sign-in page
- `index.html` — Main feed (post-login)

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons 1.11

## How to Run
Open `login.html` in a browser. Click **Sign in** to navigate to the feed.
